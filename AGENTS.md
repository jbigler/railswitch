# AGENTS.md — railswitch

Go CLI (`railswitch`, module `github.com/jbigler/railswitch`) that runs Rails dev environments on rootless podman via Quadlet.
Spec: `handoff/HANDOFF.md`; decisions D1–D80: `docs/superpowers/plans/2026-10-25-railswitch-roadmap.md`.

## Commands
- `make check` before every commit: `gofmt -l` empty, `go vet ./...`, `staticcheck ./...`, `go test ./...`.
- `make build` → `./railswitch` (`VERSION=` sets `buildinfo.Version`).
- Integration tests carry `//go:build integration`; the full end-to-end test needs a systemd user session and is a manual run.

## CLI (Stage 4 additions)
- `agent [--new-term] [<name>] [-- args]` (runs `up` first; on-demand agents get a transient container, service agents are started then attached to; refused while another agent of the worktree runs, D62), `agent stop [<name>]`, `agent add <name> [--use <ref>] [--run on-demand|service]` (D63: adds `[agents.<name>]`, declares its package secrets, adds it to git-host secrets' services, locks and ejects missing agent Containerfiles; workspace-wide), `--json agent ls` (rows carry `running`); `up` never starts an agent; `project new --agent name=ref` (repeatable) or `--agent none` (default: the built-in package with `default = true`).
- `nvim`, `nvim update`, `nvim reset-config [--yes]`; `hooks check | backup [<hook>…] | restore [--force]`; `db dump` (every database the option's `[dump] list` prints, one `<db>.dump` each; files 0644 in `<ws>/db-dumps/`, dir 0755); `secret add --git-signing` (key piped on stdin).
- `project.toml`: `[tools.nvim] config_repo`/`config_ref` (replaces `[tools] nvim = true`, which is refused); `[agents.<n>] use` (`<name>@N` or `local:<name>@N` → `<ws>/agents/<name>/`), `run` (`on-demand`|`service`), `env`, `allow`.
- `config.toml` `[[mount]]` (D57): machine-local mounts per service (`relabel = false` drops `z`; see docs/nvim.md); `doctor` checks them (`machine mounts`).
- `doctor` checks carry `warn` (JSON `"warn"`): a warning prints `warn` and doesn't change the exit code; `git-guard` findings are warnings.
- Agents (D55, C7, C10): service `agent-<n>`, own firewall profile `agent-<n>` (allow file `agent-<n>.allow`), always `enforce`. Home: the bind dir `<ws>/.railswitch/agent-home/<slug>/<n>` at `/home/appuser` (`z`), apart from nvim's `.railswitch/home/<slug>`; render pre-creates every mount point under a home (else the runtime makes them root-owned); `down` keeps it, `wt rm --force` deletes it. git-guard: every writable `{base.git}` mount gets `{base.git}/hooks` mounted `ro,z` on top.
- Genericity: no `filial` in non-test code or built-in packs, `claude` only under `internal/pack/builtin/agents/claude/`, terminal names only in `internal/term/` (`TestGenericity` in `internal/`).

Restart lists count running worktrees whose stamped units or mounted package assets change.
- `pack file show <ref> <path> [--json]` (`{path, text, hash}`; built-ins read-only), `pack file write <ref> <path> --if-hash <h> [--dry-run] [--restart]` (`--if-hash ""` adds; `--dry-run --json` `{hash, used, steps, restart, errors}`), `pack file rm <ref> <path> --if-hash <h>` (never the manifest): `local:` refs only, at the version their manifest declares; agents too (`agents/<name>/`: any top-level file or `entrypoints/<file>`); paths are D93's allowlist (`pack.CheckFilePath`), symlinked package dir, `entrypoints/`, `initdb/` or file refused; the package must load from an in-memory copy (`pack.Catalog.WithFile`); "used" is read from `project.toml` (`usesRef`), and a used package is judged on `workspace.LoadEdited`, so a package broken on disk can be repaired; it is locked and rendered through `commit`, an unused one only written; `.sh` 0755. `pack show --json` gains `files` (every package; built-in `.sh` executable) and shows agents (`kind: "agent"`); `pack eject` copies agents to `agents/<name>/`; `project show` gains `used`. `pack new --option <slot> <name>`: `options/<name>/` with an `option.toml` that loads and a `README.md`.

## CLI (Stage 7a additions)
- `lock --review [--json]` (D97: `{hash, flags, packages[]{ref,kind,status,from,to,also_locked_in,files[]{path,status,diff,flags[]{check,line,text}}}, restart}`; `line` 1-based in the new file, 0 for a manifest flag), `lock --accept <hash> [--restart]` (refuses another hash; writes through `commit`; exit 3 written, restart failed); plain `lock` writes only with no `stack.lock` or nothing to review, else prints the review and exits 1. `overview --json` gains `review_pending`.
- Store (D96): `internal/lockstore`, `<data>/locked/<sha256>/`, verified by hash on every `Get` (tampered = missing); every lock write `Put`s what it pins. A package whose content changed under its locked ref runs the stored accepted copy (`Catalog.WithPackage` at `workspace.load`, before `Resolve`; `Workspace.Pending`). `workspace.Lock(ctx, root, Accept)`: `lock --accept` all, `pack file write` only the file it writes (`Accept.Edit`: any other difference from the stored accepted copy refuses), every other caller none (a waiting update keeps its entry; without a usable copy the write refuses); a dropped entry is remembered in `stack.lock` `[[removed]]` (newest 32), and a ref coming back is locked at it, not at its current content. `Lock` and `Review` resolve on the raw catalog. Ejects (`containerfile eject`/`new`, `containerfile show`'s default, `agent add`, `pack eject` of a locked built-in) copy from `workspace.Accepted`, never the raw catalog; `agent add` restores `project.toml` when the lock refuses. Checks (D98): `internal/review`.

## CLI (Stage 7b additions)
- `signer ls` (`--json`: `{libraries[]{id,last_serial,keys[]{key,fingerprint,added},revoked[]{fingerprint}}}`, arrays never null), `signer add <library> <public-key-file|->` (one key line; `-` reads stdin; refuses a revoked or malformed key), `signer rm <library> <fingerprint>` (distrust; an entry with revocations or a `last_serial` stays), `signer revoke <library> <fingerprint>` (to the revoked list: never trusted again by `add`, `library trust` or a rotation; no command undoes it; the machine page's Revoke): `signers.toml` in the config dir (D100, 0600, atomic), no workspace; every load→change→save holds a flock on `signers.toml.lock` (`signing.UpdateTrust`, the only writer).
- `library verify <dir> [--json]` (`signing.Result`; exit 0 only when `trusted`, the JSON printed either way; a trusted verify saves the serial and applies `[[revoke]]`), `library trust <dir> --fingerprint <fp> [--rotation | --new-signer]` (re-verifies; `fp` must be the reported signer, or with `--rotation` the new key; an unvouched signer for a library with keys or revocations (`known_library`) needs `--new-signer`; anything else refuses with `signers.toml` untouched; then verifies again and saves). Publisher (docs/libraries.md): `library index <dir> --library <id> [--serial <n>]` (keeps `[[rotate]]`/`[[revoke]]`; serial default current + 1; refuses a serial not above the current one or another id), `library sign <dir> --key <file>`, `library rotate <dir> --old-key <file> --new <pubfile>` (bumps the serial). A trusted verify records `last_serial` and `last_index` (sha256 of `library.toml`); another index at `last_serial` is `rolled-back`. Signing is `ssh-keygen -Y sign` with `sys.NoTimeout` and the terminal attached (passphrase, touch) over a copy in a temp dir (ssh-keygen keeps an old `.sig` when it can't ask). Library text on a terminal goes through `safefile.Printable`.
- `doctor`: `ssh-keygen -Y` (a warning when `-Y verify` is missing). `overview --json` gains `signer_warnings` (`[]` until 7c).

## CLI (Stage 7c additions)
- `library add <url> --alias <a> [--branch <b>]` (records `libraries.toml` in the config dir, then fetches; a fetch that fails before a verdict removes the entry), `library fetch [<alias>]`, `library rm <alias>` (refused while a registered project's `project.toml` text holds `"<alias>:` or `'<alias>:`), `library ls` (`--json`: `{libraries[]{alias,url,branch,id,status,serial,commit,fetched,packages,pending{fingerprint,new_fingerprint,status,known_library}|null}}`), `library trust <alias> --fingerprint <fp> [--rotation|--new-signer]` (an alias in `libraries.toml` names its `pending/`: verified, trusted, promoted under the trust lock; any other argument is a folder). Exit 0 for `trusted`, `unknown-signer`, `rotation`.
- Fetch (D104, `internal/libraries`): `git clone --depth 1 --filter=blob:none --no-checkout` in a `sys.RuntimeTemp` dir (always removed), `ls-tree -r -z HEAD -- library.toml library.toml.sig packs options agents templates`: a symlink, submodule, non-regular mode, a path off `<kind>s/<name>/` + `pack.CheckFilePath`, > 2,000 files, a file > 1 MiB or > 64 MiB in all refuses the fetch; one `git fetch --stdin` for the listed blobs, sizes from `cat-file --batch-check`, then `cat-file blob` capped into `<data>/libraries/<alias>/staging-*`; one 5 min deadline. Verdict under `signing.UpdateTrust`: `trusted` → `current/` (renamed over; the id recorded in `libraries.toml` on first trust, later must match, never two aliases with one id), `unknown-signer`/`rotation` → `pending/` + `pending.toml`, else dropped (any non-pending verdict drops an older `pending/`); `fetch.toml` (`libraries.Record`: current's id/commit/serial/signer, the last verdict's status/fetched/reason). An error is no verdict: nothing changes. Locks: the alias (`<data>/libraries/<alias>.lock`), then `signers.toml`, then `libraries.toml`.
- Library refs (D105): `<alias>:<name>@N` (`pack.Ref.Library`, exclusive with `Local`; `config.LibraryRef`, `config.ValidAlias`: `[a-z][a-z0-9-]{0,19}`, never `local`) in `[stack] pack`, `[options]`, `[agents.<n>] use` and `from`. `pack.LoadCatalog(root, libs)`: every command loads through `workspace.LoadCatalog(root)` (the machine's `workspace.Libraries`); a library ref loads from `<data>/libraries/<alias>/current/` (fetch record `fetch.toml`, `libraries.ReadRecord`) only when its `library.toml` lists it with the sha256 the directory hashes to now (read into memory once, symlinks refused, no `ssh-keygen`). Lock entries: `source = "library <id>"`, `commit`, `signer` (`config.LockEntry.Signer`; `[[removed]]` keeps both); `workspace.Pins(e, r, libs)` compares version and where a package comes from (built in, local, library), and for a library entry its id against the library `r`'s alias names here (`libs.Alias(id)`): acme's entry never pins `evil:redis@1`; `CheckLock` and `[[removed]]` compare a library entry's whole source.
- Install (D106): a library ref new to the lock is `added` in `lock --review`; `workspace.Lock` refuses it unless `Accept.All` or `Accept.Install` names it ("installing … needs review"; a library ref the lock's tables don't pin is new, even back from `[[removed]]`, and is re-verified), so `settings apply`, `project write`, `agent add`, `project new` and a first plain `lock` refuse and restore. `workspace.Install(ctx, root, p, cat)`: the Install review (just those refs, and the exact `stack.lock` `Accept{Install}` writes). `settings preview --json` gains `install` (that `lock --review` document, or null); `settings apply --if-hash <h> --accept-install <review-hash>`; `project new --dry-run --json` gains `install`; `project new … --accept-install <hash>` (checked before the clone). Accepting a library package (install or update) re-verifies its checkout against today's `signers.toml` (`Accept.Run`, one `ssh-keygen` per library; status `trusted`, the fetch's signer, the package `signed`). `overview --json` `signer_warnings: [{ref, library, fingerprint}]` (never null): locked library packages whose lock `signer` is distrusted or revoked (`Workspace.SignerWarnings`).
- Tools and the agent base in the lock (D107): `stack.lock` `[tool.<name>]` (nvim, when `[tools.nvim]` is set) and `[base.agent]` (when the project has agents), no version; `pack.KindTool`/`pack.KindBase` (`pack.AgentBaseRef` = `agent-base`, `Catalog.AgentBase`, `Stack.AgentBase`, `Catalog.WithPackage` for both); stored, run from the store and reviewed like packages (review kinds `tool`, `base`). Ejects (`stackBuiltins`) read the agent base from the accepted stack, never the embedded FS. A pre-7c lock lacks both: pending review until `lock --accept`. `containerfile eject`/`new`/`show`'s default refuse a library ref the lock doesn't pin (`workspace.CheckInstalled`: "… is not installed: review it first").

## Global constraints
- Paths honour `XDG_CONFIG_HOME`/`XDG_DATA_HOME`: config `~/.config/railswitch/`, data `~/.local/share/railswitch/`, Quadlet output `~/.config/containers/systemd/`.
- Git calls that touch a remote (`project new`/`init`/`detect`, `wt add`'s fetch, `library add`/`fetch`) pass `sys.GitProtocols` (only https, ssh, git, file) and check user values with `sys.GitArg` (no leading `-`, no `<transport>::`).
- Commands: argv only, never a shell; every call through `sys.Runner` with a timeout (`sys.Cmd.Timeout`, default 30 s) or explicit `sys.NoTimeout` (`logs -f`, `exec`, `deps`, `agent`, `nvim`, `library sign`/`rotate`). No podman Go bindings.
- Secrets (D33): values only on stdin — never argv, written files, env files, logs or job output. No host SSH agent, `~/.ssh` or host gitconfig mounted into containers. Commit signing is opt-in (D61): a file-delivered secret with `git_signing = true` (`secret add --git-signing`) holds a signing-only SSH key; its services get `gpg.format=ssh`, `user.signingkey=/run/secrets/<name>`, `commit.gpgsign`/`tag.gpgsign` via `GIT_CONFIG_*`.
- Dependencies: stdlib + `github.com/BurntSushi/toml` only. No-echo prompt uses `syscall` TCGETS/TCSETS.
- Firewall files (D117): `hook.sh`/`firewall.sh` run with `umask 077`; the hook keeps `state/` 0700 and its files and `hook.log` 0600.
- Hardening (D34): every container has `NoNewPrivileges=true`, `Memory=`, `PidsLimit=`; app/deps/worker/tool/agent also `DropCapability=all`; browser keeps `AddCapability=NET_ADMIN`/`NET_RAW`, no `DropCapability`.
- Schema (D39): `project.toml`, `stack.lock`, `registry.toml`, `config.toml`, `dashboard.toml` carry `schema = 1`; a higher schema is refused ("written by a newer railswitch").
- `--json` (D40): every read command (`env`, `status`, `overview`, `wt ls`, `project ls`, `secret ls`, `containerfile list`, `containerfile show`, `pack show`, `pack ls`, `pack file show`, `doctor`, `machine`, `agent ls`, `pr ls`, `task ls`, `dashboard colors`, `settings preview`, `project show`, `project detect`, `lock --review`, `signer ls`, `library verify`, `library ls`, `template ls`, `template show`, `template check`, `template import`, `pack import`, `fw show`, `gc`) prints one JSON document; schemas in `docs/json.md`.
- Unit tests need no podman, systemd, gh or network (`git`, `bash` allowed; use `internal/sys/systest` Fake).
- Ports publish only on `127.0.0.1:<host>:<ctr>`.
- Remove objects by exact name, never `--filter`/regex. Never `git worktree prune`.
- Files inside a worktree are read only via `safefile.Read` (regular files, ≤ 1 MiB); text from them (or from a status file) printed on a terminal goes through `safefile.Printable` (branch names included).
- Pinned: subnet pool `10.214.0.0/16`, one `/24` per project (skipping /24s any existing podman network uses), gateway `.1`, Traefik `.2`, dynamic `10.214.<n>.128/25`; `10.214.255.0/24` reserved for the machine network `railswitch_machine` (gateway `.1`, Traefik `.2`, Dozzle `.3`), never a project's; every railswitch network (proxy, dev, machine) `isolate=strict`; dev network MTU 1400; ports DB 55432+ID, Ruby debug 33000+ID, Neovim 17000+ID, Playwright 18888+ID, App share 13000+ID, Storage share 19000+ID; two different port bases on one machine ≥ 100 (`MaxWorktreeID + 1`) apart; worktree slug ≤ 40 chars; `LogDriver=journald` for long-running units, `passthrough` for oneshots (D64).
- railswitch's own CI lives in `.github/workflows/`; railswitch never generates or touches a project's CI (D41).
- Dashboard (D73, D74): unit `railswitch-dashboard.service` (plain systemd user unit, `Wants=` from every app unit, never blocks `up`) on `127.0.0.1:7700` (`http://railswitch.localhost:7700/`); token `~/.local/share/railswitch/dashboard/token` 0600; every request needs the cookie, POST also `Origin`.

## Package map
- `cmd/railswitch` — entry point → `cli.Main`.
- `internal/cli` — flag dispatch, one file per command group.
- `internal/sys` (+ `systest`) — Runner/Cmd/Result, Fake runner; `Cmd.KillGrace` (own process group, SIGTERM then SIGKILL on cancel).
- `internal/jobs` — the dashboard's job hub: one child per job in a `systemd-run --user --scope`, log file 0600, kept output capped, one job per worktree (project-level jobs block the project), last 20 kept.
- `internal/prs` — `pr ls`: `gh pr list` JSON → per-branch PR state, checks and review; the repo from `project.toml`'s URL; fork PRs (`isCrossRepository`) ignored.
- `internal/settings` — `settings preview`: the edit list (strict JSON), applied by `config`'s line editor; each edit judged against the project with the edits before it, by rendering both in memory (`workspace.WithProject`, no stack.lock write) and comparing every worktree's non-cache volumes and the app's env; restart = running worktrees whose stamped units or mounted package assets change; `Compare` judges a file change (changed build tags, restart) for `containerfile write` and `pack file write`.
- `internal/dashconf` — `dashboard.toml`: presets, per-mode token overrides, set/reset, contrast warnings.
- `internal/web` — the dashboard: guard (Host, token cookie, Origin on POST, CSP), pollers (`overview` 2 s with a page open, else 10 s; `pr ls` 60 s), SSE fragment diffs and notifications, actions as `internal/jobs` jobs; `/new` creates a project (`project detect`, `project new --dry-run`, then `project new` as a job keyed by the new prefix; docs/dashboard.md). Reads only through `railswitch --json` (its `CLI`), never a package's files; templates and static files embedded; no inline script or style (colours at `/theme.css`).
- `internal/safefile` — hostile-file reads; `Printable` (control characters → spaces). `internal/naming` — sanitize, object/unit names.
- `internal/placeholder`, `internal/config`, `internal/pack` (+ `builtin`; the package format and local packs: `docs/packs.md`), `internal/version`.
- `internal/machine` — dirs, registry, proxy, machine config.
