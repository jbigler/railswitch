# RailSwitch guide

for the details.

2. [Concepts](concepts.md): workspaces and worktrees, packs and options,

3. [Agents](agents.md): connecting an AI agent, its sandbox and its
   secrets.
4. [The editor](editor.md): Neovim in a container, with your own config.
5. [The firewall](firewall.md): what each container may reach, and how to
   allow more.
6. [Customizing a project](customizing.md): Settings, Containerfiles,
   your own packages, update reviews.
7. [Sharing](sharing.md): templates, packages and libraries.
