How switching behaves

  • One project at a time. The page opens on the project you used last; a worktree’s URL names its project, so a bookmark opens that one instead.
  • Agents waiting in other projects still show: in the strip above the list, in the switcher’s ◆ counts and in the header’s total. Notifications fire for every project.
  • Searching the switcher finds worktrees in any project, and picking one switches to its project.
  • The task palette (:) runs tasks for the selected worktree’s project; project-wide tasks say which project they act on.
  • Each job in the actions panel is labelled with its project.
