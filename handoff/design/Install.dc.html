What gets locked

Each pack and option is recorded with its commit and a hash of its content; each image with the digest it resolved to on first pull. Until you review an update, every worktree and every teammate gets exactly these. A library that later changes a published version cannot change your project: the hash would no longer match and install stops.

Install

  • Built-in packs and options are locked to the version of wt itself.
  • Ones you made on this host are locked by content hash.
  • An unsigned library, or a signer you have not trusted before, is shown but cannot be installed until you trust it.
