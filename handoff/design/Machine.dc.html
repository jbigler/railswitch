This machine

One proxy, one dashboard and one set of ports, shared by every project here. A project never runs its own: it registers its worktrees, and the machine gives them hostnames and ports that cannot collide with another project’s.

Hostnames

Every worktree is named under its project, so the same branch in two projects never claims the same host. Browsers and systemd-resolved send every *.localhost name to this machine, so nothing needs adding to /etc/hosts.

Who can reach whom
{{n.net}} wt-traefik {{n.traefik}} {{n.prefix}} worktrees only

A worktree joins only its own project’s proxy and dev networks, so no container can reach another project’s. Only Traefik sits on all of them. Each container carries a traefik.docker.network=<prefix>_proxy label so Traefik routes to it over the right network, and its --add-host entries point at Traefik’s .2 on that same network.

New project: its subnet is taken from the pool and Traefik is connected to the new network at .2 (podman network connect --ip), so running projects are not interrupted. Checks: port 80 allowed for rootless podman (allow-ports), every pool subnet free or ours, Traefik on every project network, podman.socket on.

Moving from one proxy per project

  1. filial_proxy stays as Filial’s proxy network, with the same subnet (10.214.0.0/24) and the first slot in the pool.
  2. filial-traefik, filial-dozzle and filial-dashboard stop; wt-traefik starts on the same ports and joins filial_proxy at the address the old one had, 10.214.0.2.
  3. Worktrees need no restart: their network, firewall annotation and --add-host entries are unchanged. Routes drop for the seconds between the two Traefiks.
  4. With short names on for Filial, every current URL keeps working.
